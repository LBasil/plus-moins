# Plus ou Moins

Jeu de devinette de nombre en JavaScript vanilla (Bootstrap 5), sans build.

Il faut trouver un nombre entre 1 et 100 en 10 essais, avec des indications « plus » et « moins ». Une fois gagné, un mode boss propose un nombre entre 1 et 1000. Le jeu est raconté par de courts textes de narration.

## Lancer

Ouvrir `index.html` dans un navigateur.

Démo : https://plus-moins.vercel.app/
